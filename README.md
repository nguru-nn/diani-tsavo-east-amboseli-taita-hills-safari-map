# diani-tsavo-east-amboseli-taita-hills-safari-map
Interactive 3D Mapbox map of a 4-day road safari from Diani Beach to Tsavo East, Amboseli and the Taita Hills (Salt Lick Lodge), Kenya. It shows an in-park game drive route, a lodge for each night, satellite terrain and a clickable day-by-day itinerary. Full tour: safarikenia.com.pl
